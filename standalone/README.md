# VIGILIA - Standalone

This folder contains the browser-native game code. It uses only CSS,
JavaScript ES modules, `localStorage`, and the Web Audio API.

## Run

Use the single project entry point: `../index.html`.

## Files

```text
standalone/
  styles.css
  src/
    main.js
    render.js
    cardRenderer.js
    data/
    lib/
    scenes/
```

There is no build step and no external runtime.
